# b1-site

Public GitHub Pages leaf for a protein–ligand cofolding confidence study on Runs N' Poses.

- Live: https://peterponyu.github.io/b1-site/
- Repository: https://github.com/PeterPonyu/b1-site
- Archive: https://doi.org/10.5281/zenodo.21870002

This repository is the Next.js static export. It names the research object and points at the archive. It does not post figures or numeric results. It is not a published article and has no article DOI. It does not include journal skins, cover letters, or a method workbench.

```bash
NEXT_PUBLIC_BASE_PATH=/b1-site npm ci && npm run build && npm run verify
```
